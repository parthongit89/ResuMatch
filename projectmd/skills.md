# ResuMatch - Tech Stack & Developer Skills Required

## 1. Flask Backend Developer Stack & Libraries
- **Core Web Framework**: `Flask` (App Factory pattern, Blueprints, REST controllers)
- **Database & ORM**: `Flask-SQLAlchemy` (SQLAlchemy 2.0 ORM), `Flask-Migrate` (Alembic schema migrations), `psycopg2-binary` (PostgreSQL driver).
- **Authentication & Security**: `Flask-JWT-Extended` (JWT Bearer Token Auth), `bcrypt` / `Werkzeug.security` (Password hashing), `Flask-CORS` (Cross-origin resource sharing), `Flask-Limiter` (Rate limiting).
- **Validation & Serialization**: `marshmallow` (Request schema validation and JSON serialization).
- **PDF Generation & Export**: `WeasyPrint` / `ReportLab` (HTML/CSS to PDF rendering engine).
- **WSGI & Deployment**: `gunicorn` (Production WSGI HTTP Server for Render deployment), `python-dotenv` (Environment variable management).

---

## 2. Frontend Developer Skills & Requirements
- **Framework**: React.js / Next.js, HTML5, CSS3, Tailwind CSS.
- **State Management**: React Context API / Redux Toolkit / Zustand (for 7-step session state persistence).
- **HTTP & Auth**: Axios with Auth Interceptors, LocalStorage/Cookie session management.
- **PDF & Preview**: Client-side HTML rendering engine / react-pdf / jspdf.
