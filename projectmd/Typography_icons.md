# ResuMatch - Typography & Iconography Specifications

## 1. Typography Pairings for Resumes

### Combination A: Sans-Serif Modern (Default / ATS Recommended)
- **Header Font**: `Inter` / `Roboto` (Weights: 600 SemiBold, 700 Bold)
- **Body Font**: `Inter` / `Open Sans` (Weights: 400 Regular, 500 Medium)
- **Use Case**: Tech, Startups, Product Management, Engineering.

### Combination B: Classical Serif & Sans
- **Header Font**: `Merriweather` / `Lora` (Weights: 700 Bold)
- **Body Font**: `Source Sans Pro` / `Calibri` (Weights: 400 Regular)
- **Use Case**: Legal, Finance, Executive Roles, Academia.

---

## 2. Iconography Standards
- **Icon Library**: Lucide Icons / FontAwesome Free.
- **Usage**:
  - Email: `Mail` icon
  - Phone: `Phone` icon
  - Location: `MapPin` icon
  - LinkedIn: `Linkedin` icon
  - GitHub: `Github` icon
  - Portfolio: `Globe` / `Link` icon
  - Session Navigation: `ChevronRight`, `ChevronLeft`, `CheckCircle`
